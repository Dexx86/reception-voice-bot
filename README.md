# Free Reception Bot

Double-click `OPEN-IN-EDGE.cmd`. It opens the bot in Microsoft Edge at `http://localhost:8080`, where you can allow microphone access. It listens, provides a spoken response, and keeps visitor notes only in the open browser tab.

This is a free demo: it has no account, API key, hosting, external storage, or phone number. Browser speech recognition may use the browser vendor's service, so do not use it for confidential information. The Codex in-app browser does not support this voice feature reliably; use Edge or Chrome.
